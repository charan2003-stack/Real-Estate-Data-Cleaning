# Real Estate Data Cleaning & EDA

## 📌 Project Overview

This project focuses on cleaning and analyzing real estate data using Python and Pandas.

The project demonstrates how raw real-world data can be cleaned, validated, and prepared for Exploratory Data Analysis (EDA).

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Data Cleaning
- Exploratory Data Analysis (EDA)

## 🔍 Project Features

### 1. Data Cleaning
Cleaned the real estate dataset using Python and Pandas.

### 2. Missing Value Handling
Identified missing values in the dataset and handled them using appropriate techniques.

### 3. Data Validation
Performed data validation to ensure the dataset was suitable for analysis.

### 4. Mean-Based Imputation
Used mean-based imputation to fill missing numerical values and prepare the dataset for further analysis.
